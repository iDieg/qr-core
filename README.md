# QR-Core

Dynamic QR code management web application built with PHP 8 (OOP / MVC), MySQL (PDO Singleton), Vue.js 3, and Tailwind CSS.

## Environment Setup

1. Copy `.env.example` to `.env` and set your MySQL database credentials and `APP_URL`.
2. Import `schema.sql` into your MySQL database.
3. Ensure `qrs/` is writable by the web server user.
4. Default demo account: `usuario@youtube.com` / `password`.
